# 📜 Changelog

All notable changes to **Smart Tasbeeh** will be documented in this file.

---

## [1.1.0] - 2026-02-28

This update introduces powerful organization tools, improved accessibility, and major stability enhancements to deliver a smoother and more refined experience.

### ✨ Added
- **Textual Word Representation**: Displays the count in words (e.g., "One", "Two") below the main counter.
- **Action Labels**: Added descriptive text labels for all primary action buttons for better clarity.

### 🎨 Improved
- **Dashboard Header**: Redesigned History header with a modern look and record count badge.
- **Fluid Text Scaling**: Implemented dynamic typography that scales consistently across all device sizes.
- **Icon-Based Controls**: Updated Sound and Vibration settings to use intuitive icon-based interaction.
- **Enhanced Update Dialog**: Refined "Update Count" dialog with a side-by-side comparison of old vs new counts.
- **Accessibility**: Improved color contrast and added screen reader labels for icons.

### 🐞 Fixed
- **Slider Crash**: Resolved fatal exception in Auto-Count slider value validation.
- **Null-Safety**: Added robust null-pointer guards for all dialog interactions to prevent crashes.
- **Code Cleanup**: Addressed numerous deprecated method warnings and optimized internal logic.

---

## [1.0.1] - 2026-02-22

### 🐞 Fixed
- **Landscape Crash**: Fixed crash occurring in the Analysis screen when switching to landscape mode.
- **Orientation Stability**: Improved layout stability and responsiveness for landscape orientation.
- **UI Refinement**: Minor UI tweaks for better button alignment and spacing.

---

## [1.0.0] - 2026-02-19

### 🚀 Initial Release
- **Advanced Counter**: Movable button, Tap Anywhere, and Haptic/Sound feedback.
- **Auto-Count Mode**: Hands-free counting with adjustable speed (0.1s to 60s).
- **Target Mode**: Set goals with vibration and dialog completion alerts.
- **History & Analysis**: Save sessions, pin up to 3 favorites, and view zikr performance stats.
- **Premium UI**: Full Dark Mode support and landscape optimization for tablets/foldables.
